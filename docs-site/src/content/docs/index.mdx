Docker Cleanup Pro is a high-performance CLI tool designed to help you maintain a clean Docker environment by removing unused containers, images, volumes, and networks.

## Key Features

- **Automated Cleanup**: Basic, Advanced, and Total cleanup levels.
- **Detailed Reporting**: Export disk usage statistics to JSON or Markdown.
- **Safety First**: Dry-run mode to preview changes before execution.
- **Age Filtering**: Target resources older than a specific duration (e.g., `10d`, `2w`).

## Getting Started

To get started with Docker Cleanup Pro, follow our [Installation Guide](guides/installation) or jump straight into the [Quickstart](guides/quickstart).

### Basic Command

```bash
docker-cleanup bc --older-than 7d
```
